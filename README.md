# Sakura Ex Command Palette 0.3.0

Generated By OpenAI

サクラエディタ 2.4.3 の Python マクロを使う Vim/Ex 風コマンドパレットです。

## 設計

- Python の通常の `import` のみを使用
- `eval` / `exec` / ActiveX / 実行時ソース読み込みなし
- `command_palette.py` は入力UIだけ
- `parser.py` はEx構文解析だけ
- `dispatcher.py` はディスパッチだけ
- `commands/` はコマンド実装
- `context.py` はサクラエディタAPIとの境界

## Lazy Load

独自のLazyLoaderは実装しません。Python標準のimport機構を使います。
同一Pythonインタプリタ内であれば `sys.modules` による通常のimportキャッシュが利用されます。
一方、サクラエディタのPythonマクロのライフサイクルを跨いだ常駐は保証しません。

## インストール

サクラエディタのプラグイン導入機能からZIPを導入してください。
プラグインには通常コマンドと起動時実行コマンドを登録しています。

## 注意

Python APIのUI・選択操作はサクラエディタ2.4.3のPythonバインディングに依存します。
`context.py` にAPIを集約しているので、ビルド/配布版のAPI差異があっても修正箇所を限定できます。
